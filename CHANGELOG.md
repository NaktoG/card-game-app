# Changelog

Todas las versiones relevantes se documentarán en este archivo.

## 1.0.0 - 2026-07-13

### Added

- Reconstrucción completa con React, Vite y TypeScript.
- UI responsive dark-first con Framer Motion.
- Registro por nickname local.
- Ranking local con `localStorage`.
- i18n español/inglés.
- Sonido con Howler.js.
- Tests unitarios para lógica crítica del juego.
- Documentación profesional y runbook.
- CI/CD para GitHub Pages.

### Improved

- Segunda pasada visual premium con auroras, partículas, panels glass y mejores cartas.
- Modal final con confetti animado.
- Ranking y scoreboard con tratamiento visual premium.

### Added

- PWA con manifest, service worker, iconos SVG y fallback offline.
- Metadatos SEO/Open Graph y Twitter Card.
- Footer responsive con enlace directo al repositorio en GitHub.

### Changed

- Favicon e iconos PWA reemplazados por una identidad visual basada en cartas y palos.
